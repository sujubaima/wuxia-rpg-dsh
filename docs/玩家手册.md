# 武侠 RPG 玩家手册

这是一款由 AI 担任主持人（GM）的文字武侠 RPG。你用自然语言描述行动，GM 负责理解意图、推演江湖，引擎负责数值结算、状态变化与存档。

不需要背命令。先读完“开始游戏”和“如何行动”即可开玩，其余内容遇到时再查。

---

## 1. 开始游戏

输入：

```text
开始游戏
```

标题界面可以创建角色或读取存档。

### 创建角色

建号分三步。

#### 第一步：身份

填写姓名、性别和年龄。年龄范围为 16～80 岁。

```text
沈听雪，女，18岁
```

#### 第二步：资质

你有三组点数，每项最多分配 12 点：

| 点数池 | 总点数 | 可分配项目 |
|---|---:|---|
| 一级属性 | 24 | 内功、力道、身法、根骨 |
| 武艺 | 36 | 搏击、剑法、刀法、长兵、奇门、暗器 |
| 技艺 | 36 | 音律、弈棋、诗书、绘画、医术、博物 |

还要为四组极性各选一项：阴/阳、刚/柔、动/静、巧/拙。选择“中”则不作修正。极性都是取舍，没有绝对优劣。

不清楚效果时输入 `属性含义`；不想手动分配时输入 `随机分配`。

#### 第三步：入门武学

任选一门，并获得对应兵器：

| 门类 | 武学 | 兵器 |
|---|---|---|
| 搏击 | 丐帮《百缠手》 | 拳套 |
| 剑法 | 武当派《太乙玄门剑》 | 长剑 |
| 刀法 | 锦衣卫《开阖刀法》 | 朴刀 |
| 长兵 | 少林寺《夜叉棍法》 | 长棍 |
| 暗器 | 乌衣门《蜻蜓点水势》 | 飞刀 |
| 奇门 | 峨眉派《分水刺》 | 峨眉刺 |

可先输入 `武学详情` 查看招式、消耗和十境增益。

建号完成后，角色还会获得：

- 500 铜钱
- 小还丹 ×2
- 补气丸 ×2
- 布衣

随后系统随机确定初始地区与时间，GM 给出开场剧情。

## 2. 如何行动

### 只描述意图，不预写结果

这是最重要的规则。

```text
可以：我拔剑攻击黑衣人
可以：搜查书架后面有没有暗格
可以：让队里的医师替伤者诊脉

不可以：我一剑杀死黑衣人
不可以：我从暗格里找到绝世秘籍
```

你决定角色做什么；能否成功、产生什么结果，由规则、判定和剧情共同决定。

### 直接说人话

常见说法：

| 目的 | 示例 |
|---|---|
| 移动 | `前往百兵堂`、`去杭州` |
| 交谈 | `与掌柜谈谈`、`向船夫打听昨夜的事` |
| 调查 | `观察尸体`、`搜查厢房` |
| 交易 | `买两颗补气丸`、`把朴刀卖给铁匠` |
| 使用物品 | `服用小还丹`、`研读这本秘籍` |
| 战斗 | `挑战那名刀客`、`攻击拦路人` |
| 休息 | `在客栈住一夜`、`在野外休息两个时辰` |
| 队友行动 | `让骆逸去交涉`、`请队友替我辨毒` |

一句话可以包含多个意图，但有先后依赖时，系统会分步执行。例如“去杭州打听盐帮”会先处理旅途，抵达后再继续打听。

### 查看与配置

这些操作通常不推进世界时间：

- `角色信息`
- `查看背包`
- `查看武学`
- `查看线索`
- `查看地图`
- `配置装备`
- `配置武学`
- `配置物品`
- `精进 <武学名>`
- `保存游戏`
- `读档`

输入 `指令查询` 可以查看当前界面支持的操作。

## 3. 读懂角色

### 一级属性

| 属性 | 主要影响 |
|---|---|
| 内功 | 攻击力、内力上限 |
| 力道 | 暴击、精准 |
| 身法 | 速度、防御力 |
| 根骨 | 识破、气血上限 |

### 极性

极性会增强一种派生能力，同时削弱另一种：

- 阴：内力更高、攻击较低；阳相反
- 刚：暴击更高、精准较低；柔相反
- 动：速度更高、防御较低；静相反
- 巧：识破更高、气血较低；拙相反
- 中：不增不减

### 武艺

武艺决定角色对某类武学的掌握。使用对应武学时，自己的武艺越高、对方同类武艺越低，伤害越有利。

### 技艺

技艺用于战斗外的专业行动：

| 技艺 | 常见用途 |
|---|---|
| 音律 | 奏乐、辨曲、以乐传意 |
| 弈棋 | 手谈、推演、破解棋局 |
| 诗书 | 典籍、文书、暗语、考据 |
| 绘画 | 鉴画、制图、辨伪 |
| 医术 | 诊疗、辨毒、验伤、识药 |
| 博物 | 察觉隐藏、识别器物、采掘 |

遇到需要判定的行动时，GM 会选择合适的属性或技艺。你也可以指定某位队友出面。

### 资源

- **气血**：归零时在战斗中败阵，但不会自动死亡。
- **内力**：施展武学的主要消耗。
- **体力**：大世界行动资源，上限 100。
- **经验**：用于精进武学，主要来自战斗胜利和线索进展。
- **铜钱**：1 两 = 1000 钱，用于交易、投宿和远行。

## 4. 游历江湖

### 时间与体力

游戏以“刻”计时：

- 1 时辰 = 8 刻
- 1 天 = 96 刻

时间会影响人物出没、商铺营业和事件发生。交谈、调查、交易、赶路等行为会消耗体力并推进时间；查看信息、配置和存档通常不会。

### 移动

世界分为大区域和区域内地点。

- **区域内**：沿场景图自动寻路。每经过一段路消耗 5 体力、4 刻。
- **跨区域**：必须在驿站或港口乘舟车。旅费和耗时取决于线路，抵达时体力补满。

主动移动后可能触发遭遇、发现、天气、传闻或求助等随机事件。

### 休息

休息按完整时辰恢复；不足一个时辰的零头只计费用和时间，不计该时辰恢复。

| 等级 | 常见场所 | 费用 | 每时辰恢复 |
|---|---|---:|---|
| 露宿 | 野外、街头 | 免费 | 体力 10；不回气血、内力 |
| 简朴 | 通铺、民宿 | 4 钱/刻 | 体力 15；气血、内力各回上限 15% |
| 中等 | 上房 | 5 钱/刻 | 体力 20；气血、内力各回上限 20% |
| 奢华 | 天字号房 | 6 钱/刻 | 体力 25；气血、内力各回上限 25% |

气血和内力不会因时间流逝自动恢复，必须依靠休息、物品或明确效果。

### NPC 与队伍

NPC 对角色的关系度范围为 0～100。关系越好，越容易交易、透露消息或接受邀请；关系过低可能拒绝、离队或敌对。

队伍最多 4 人，包含主角。队友会共同参战，也可以替主角交谈、调查或判定。遣散队友通常要支付费用；铜钱不足时会损害关系。

### 线索

线索是剧情进展的主要记录。新信息出现后会自动进入线索栏；获得关键情报、形成转折或解决事件时，线索会推进并可能奖励经验、物品或铜钱。

不必把线索当作必须完成的任务。它可以停滞、分叉或被外界事件推动。

## 5. 成长与配装

### 武学十境

每门武学有 1～10 级。精进需要经验，境界越高消耗越多；高品级武学也更昂贵。

境界增益可能包括：

- 提高威力
- 降低内力消耗
- 缩短冷却
- 提高特效发动率或持续时间
- 提高暴击倍率
- 解锁新特效
- 反哺一级属性、武艺或二级属性

秘籍可以直接教会一门未学武学；已经学会时，通常免费精进一层。

### 心法

心法不能作为主动攻击，也不占主动武学携带名额。选择“运转心法”后，它会在开战时自动施加已解锁的效果。

### 装备

装备有五个槽位：

- 武器 1
- 武器 2
- 护甲
- 饰品
- 冠巾

剑法、刀法、长兵、奇门和暗器需要装备对应兵器；搏击不受武器限制。两只武器槽可以携带不同兵器，方便切换套路。

### 战斗携带

- 主动武学最多携带 4 门
- 战斗消耗品最多携带 4 类
- 心法不占主动武学名额
- 背包容量不受这两个上场限制影响

战斗前检查配装。携带列表为空时，战斗中可能只能休息、使用允许的物品或尝试脱身。

## 6. 战斗

### 开战前

战斗可能由玩家挑战、NPC 发难或随机事件触发。正式开战前会确认参战者，并选择操控方式：

- **玩家角色**：只操控主角，队友由 AI 控制
- **我方全员**：操控所有我方角色
- **AI 自动**：整场观战

非死战通常可以先尝试交涉、躲避或逃离；是否允许逃跑由当前剧情决定。

### 轮到你时

| 行动 | 说明 |
|---|---|
| `武学 <名称> <目标>` | 施展武学 |
| `使用 <物品> <目标>` | 使用已携带的战斗消耗品 |
| `休息` | 默认恢复 10% 内力，不回血 |
| `查看人物信息` | 查看战斗信息，不消耗行动 |
| `逃跑` | 尝试让当前角色脱离战斗 |
| `认输` | 我方整队判负并结束战斗 |

角色行动顺序由速度和充能决定，不是固定的一人一回合。速度越高，通常越早、越频繁行动；部分武学和状态还能直接推动或延后充能。

### 败阵、逃走与死亡

- 气血归零是**败阵**：角色退出本场战斗，但并未自动死亡。
- 逃跑成功是**逃走**：角色脱离本场，不获得胜利经验，也不能被胜方处决。
- 战斗结束后，未逃走的败方由胜方决定杀、放、俘虏或作其他处置。
- 主角被判死亡后，当前冒险按规则终结；死亡状态本身不可逆转。

### 战后结算

- 只有胜方获得战斗经验，逃走者除外。
- 经验按胜方实际参战人数分配。
- 战斗结束统一消耗 20 体力、推进 8 刻。
- 钱物不会因胜利自动进入背包；需要主动搜查尸体或现场。

## 7. 存档

- `保存游戏`：创建手动存档，需要填写标签。
- `读档`：从当前角色档的存档点中选择。
- `删除存档`：删除前会要求确认。
- 每个角色档最多保留 5 个存档点，超过后淘汰最早的存档。
- 世界交互每推进若干轮会自动存档；当前周期为 5 轮，界面会显示倒计时。

存档按角色槽位（Slot）组织，一个槽位可以有多个快照（File）。读取快照会恢复当时的角色、世界和剧情状态。

## 8. 新手建议

1. 第一次建号不必追求最优，先确定想用的武器和性格取向。
2. 长途赶路前检查体力和铜钱，跨区域先找驿站或港口。
3. 进入危险地区前配置武学、兵器和战斗物品。
4. 打不过时逃跑或认输不是失败玩法，而是保存角色的手段。
5. 多调查、多交谈。线索和技艺提供了战斗之外的成长路线。
6. 只决定行动，不替世界决定结果。

输入 `开始游戏`，然后说出你想做的第一件事。
