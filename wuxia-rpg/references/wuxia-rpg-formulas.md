# 战斗公式

## 判定流程

```
攻击方使用武学 → 闪避判定 → 命中 → 识破判定(有特效时) → 暴击判定 → 伤害计算
```

攻击型技能特效（无论施加对象）需过识破判定；非攻击型（仅对自身/友方）直接生效。

## 回合顺序（ATB）

充能条满值 100。`充能速率 = 角色速度 + 全场最高速度 / 3`。

- 开战时所有充能为 0
- 每 tick 各角色充能 += 各自速率
- 充能 ≥ 100 → 行动，充能归零
- 同时满：速度高者优先，仍同则随机
- 行动频率比恒 ≤ 2

## 闪避判定

```
闪避率 = clamp(100 - (85 + (攻击方精准 - 防守方精准) × 0.4), 0, 75)
```

闪避成功 → 本次攻击无效。

## 识破判定

仅技能附带特效时触发，按特效 `识破类型`（见 [data-schema.md](./wuxia-rpg-data-schema.md)）结算：

```
特效发动率 = clamp(75% + (攻击方识破 − 对抗值) × 0.8%, 0%, 100%)
```

| 识破类型 | 对抗值 | 掷骰粒度 |
|----------|--------|----------|
| 独立 | 目标识破 | 逐目标各掷一次 |
| 全体 | 目标识破均值 | 全技能一次，各命中目标共享 |
| 自对抗 | max(自身根骨 × 3 × 1.2 − 5, 0) | 全技能一次，各命中目标共享 |
| 无 | — | 不判定，命中即生效 |

`全体`/`自对抗` 单次掷骰结果对当次技能所有命中（且存活）目标共享：发动则皆施加，未发动则皆不施加。带技能特效而缺 `识破类型` 视为 `独立`。非攻击型（治疗/仅自身友方）特效直接生效，不走识破。

## 暴击判定

```
暴击触发率 = clamp(10% + (攻击方暴击 - 防守方暴击) × 0.2%, 0%, 75%)
```

## 伤害计算

```
技能系数 = clamp(1 + 0.6 × (攻方武艺 - 防方武艺) / (攻方武艺 + 防方武艺), 0, 2)
基础伤害 = 取整(300 × 攻击力 / (攻击力 + 3 × 防御力) × 威力倍率 × 技能系数)
暴击倍率 = clamp(120% + (攻击力 - 防御力) / (攻击力 + 防御力) × 80%, 120%, 200%)
最终伤害 = max(1, 取整(基础伤害 × 暴击倍率(如触发) × random(0.95, 1.05)))
```

- 双方武艺均 0 时系数为 1.0
- 所有伤害/恢复施加 ±5% 随机浮动后取整（休息恢复除外）

## 武器限制

| 武学类型 | 需装备武器 |
|----------|-----------|
| 剑法 | 剑 |
| 刀法 | 刀 |
| 长兵 | 长兵 |
| 奇门 | 奇门 |
| 暗器 | 暗器 |
| 搏击 | 无限制 |
| 心法 | 不可主动施展 |

武器1/武器2 任一匹配即可；无武器仅可搏击与休息。

## 休息

恢复 10% 最大内力（不回气血，不超上限）。装备/状态的 `modify_rest_recover` 钩子可改写恢复量。

## 武学有效值折算（十境）

每门武学 1～10 级，习得即 1 级，10 级为大成。武学数据的 `等级增益` 列表按等级升序，每项含 `等级`/`效果`；引擎取当前等级及以下所有同类修饰**累加**。

### 增益键名

**技能类**（作用于施展有效值）：

| 键 | 含义 |
|----|------|
| `威力倍率` | 加到基础倍率 |
| `内力消耗%` | 百分比增减（负=减免），累加后乘算 |
| `冷却时间` | 加到基础冷却（负=缩短） |
| `特效持续时间` | 回合数增减 |
| `暴击倍率` | 加到暴击倍率，同步抬高上限 |
| `解锁特效` | 布尔，达此等级才发动技能特效 |

**角色类**（修为反哺，作用于角色自身）：

| 键 | 含义 |
|----|------|
| `武艺` | 如 `{"剑法": 1}` |
| `攻击力`/`防御力`/`速度`/`精准`/`识破`/`暴击` | 二级属性加成 |
| `气血上限`/`内力上限` | 上限加成（当前值同步+） |
| `内功`/`力道`/`身法`/`根骨` | 一级属性加成，加后重新派生二级属性 |

### 折算公式

```
有效威力倍率   = 基础 + Σ威力倍率加成
有效内力消耗   = max(1, round(基础 × (1 + Σ内力消耗%/100)))
有效冷却时间   = max(0, 基础 + Σ冷却时间)
有效特效持续时间 = 基础 + Σ特效持续时间
有效暴击倍率   = 基础 + Σ暴击倍率
```

**特效门控**：十境表出现 `解锁特效` 时，当前等级 ≥ 该等级才发动特效；无此键则特效始终在线。

### 修为反哺

角色所习各武学的角色类增益累加反哺自身：在二级属性派生（极性修正）之后、装备与状态之前施加；幂等（同一战斗只施加一次）；气血/内力上限提升时当前值同步增加。

### 精进消耗

```
cost(n) = round(640 × (n−1)^0.7 × (1 + 0.25 × 品级))
```

幂律压头尾差距。品级 0 满级（Lv10）总价约 17191；品级每+1 总价 ×1.25（品级1=21487、2=25784、3=30082）。品级 0 各级消耗：2→640, 3→1040, 4→1381, 5→1689, 6→1975, 7→2243, 8→2499, 9→2744, 10→2980。

> 查十境表用 `python3 scripts/mastery.py table <角色> <武学>`。

### 心法

学习/精进同普通武学，差异：不可主动使用；经 `运转心法` 选定后战斗开始自动施加 `心法效果` 长效状态（战斗结束清除）；十境增益侧重一级属性与气血/内力上限。
