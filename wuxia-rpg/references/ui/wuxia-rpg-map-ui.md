# map-ui 渲染规范

`查看地图` 返回 `界面=map-ui` 时使用。engine 已生成邻接图，GM 不自行计算或改写。

## 模板

━━ 模板开始 ━━
### 【{当前区域} · 场景地图】 当前：{当前场景}

```text
{邻接图}
```

{驿站出口行，如无则省略}

已知地点：{地点列表}

请输入指令（前往地点、返回游历、可通过`指令查询`了解全部指令）：
━━ 模板结束 ━━

## 字段与规则

- `邻接图`：原样置于代码围栏；其中当前场景已用 `【】` 标记，地点名不再加反引号。
- `驿站出口`非空时显示「（出城：`{驿站出口}`，{驿站类型}）」；为空省略。
- `已知地点`：逐项取 `名称/标记`，名称反引号高亮；当前地点标「（当前）」、驿站出口标「（出城）」。
- 无基线场景时仍渲染当前场景根行和空地点清单，不展示场景配额等 GM 内部数据。
- 解析失败返回 message-ui，按 message-ui 文档渲染。

玩家输入“指令查询”时，先列本界面专用指令（前往地点），再读 [common-commands.md](./wuxia-rpg-common-commands.md) 补充通用指令。
