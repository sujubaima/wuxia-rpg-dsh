# mastery-ui 渲染规范

`武学精进` 指定武学但未执行精进时，engine 返回 `界面=mastery-ui`。精进成功后停留本界面，展示结算并重绘更新后的十境表。

## 模板

━━ 模板开始 ━━
### 【武学精进 · {角色}】

{结算提示，如无则省略}

{十境表}

请输入指令（精进下一境界、更换武学 [武学]、返回游历、可通过`指令查询`了解全部指令）：
━━ 模板结束 ━━

## 字段与规则

- `角色`：抬头角色名。
- `十境表`：engine 返回的完整文本，已含武学、品级、当前境界、经验、各境增益和下一境消耗，必须原样呈现，不拆解、不重组。
- `结算`：如「百缠手 精进至第2境」，逐条反引号高亮后再展示十境表。

玩家输入“指令查询”时，先列本界面专用指令（精进下一境界、更换武学），再读 [common-commands.md](./wuxia-rpg-common-commands.md) 补充通用指令。
