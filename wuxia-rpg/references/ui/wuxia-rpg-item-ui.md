# item-ui 渲染规范

`配置物品` 未带修改参数时，engine 返回 `界面=item-ui`；装、卸、换或全量设置后仍返回刷新后的 item-ui，`结算` 置于模板抬头后展示。

## 模板

━━ 模板开始 ━━
### 【更换道具 · {角色}】

{结算提示，如无则省略}

携带道具（{数量}/4）
- `{名称}`（{子类型}）×{持有数}
　效果：{效果摘要}

可换道具
- `{名称}`（{子类型}）×{持有数}
　效果：{效果摘要}

请输入指令（携带 [物品]、卸下 [物品]、替换 [新物品] [原物品]、返回游历、可通过`指令查询`了解全部指令）：
━━ 模板结束 ━━

## 字段与规则

- 只展示战斗可用消耗品，最多携带4类；数量取物品栏实际持有数。
- `携带道具`与`可换道具`逐项取 `名称/数量/子类型/使用效果`。
- 效果摘要：回复气血/内力直接写数值；施加状态写持续回合；`时序`保留正负号；净化、削减、延长写明目标状态和数量/回合；无效果显示「—」。
- 效果行以一个全角空格开头。

玩家输入“指令查询”时，先列本界面专用指令（携带、卸下、替换），再读 [common-commands.md](./wuxia-rpg-common-commands.md) 补充通用指令。
