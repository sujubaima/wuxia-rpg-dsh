# exploration-ui 渲染规范

engine/judge 返回 `界面=exploration-ui` 时使用。普通大世界 go 若无 `界面`，必须先按规则完成 judge，禁止直接拿 go 返回渲染。

## 模板

━━ 模板开始 ━━
### 【{当前位置}】 {时段} {时间}　距下次自动存档 {剩余} 轮

{剧情描写}

{状态变化提示，如无则省略}

周围情况
- {主体}{描写}

相邻出口
- {方位}（通往{邻场景}）

当前队伍　体力{体力}　金钱{金额}
- `{角色}` 气血({气血}/{气血上限}) 内力({内力}/{内力上限})

请输入指令（前往地点、与角色对话、观察场景、可通过`指令查询`了解全部指令）：
━━ 模板结束 ━━

## 字段

- `当前位置/时段/时间/剩余`：填抬头。
- `剧情描写`：原样使用 judge `当前剧情`，不再改写、扩写或省略。
- `结算`：逐项取 `变更`，反引号高亮、一行一条，置于剧情后；其中的自动存档提示照常展示。
- `场景要素`：逐项渲染为「主体（描写）」；描写缺省只写主体。`特殊指令`只供交互识别，不显示。
- `相邻出口`：严格渲染为「方位（通往邻场景）」，不叙事化；为空时保留标题并显示「（无）」。
- `体力/金钱/队伍状态`：取最新返回。金钱为铜钱数，格式化为不足千「X钱」、满千「X两X钱」。

## 判定结果

判定提示属于 `剧情描写`，不属于剧情后的状态变化提示；具体格式、位置及数据后果处理见 [exploration-rules.md](../wuxia-rpg-exploration-rules.md)「判定系统」。

## 首屏开场白

仅创建角色后的首轮 judge 使用。`当前剧情`依次包含：

1. 固定时代背景（逐字照搬）：

> 大明万历年间，天下承平日久，江湖却暗流渐起。
>
> 西域流沙之间，昔年被中原武林联手剿灭的无极教，竟以幽冥宫之名东山再起，兵锋渐指中原。而中原门派却各怀隐患，辽东与西南也隐有战端。江湖危机一触即发。

2. 据姓名、性别、年龄、人设、初始武学和落点撰写踏入江湖原由；只交代身世，不预设目的、伏笔或门派归属。
3. 首场景剧情与入门线索引子。

同时传首场景 `场景要素` 与初始 `经历概括`；建号配发产生的 `结算`逐条展示。

## 错误与渲染纪律

- judge 返回 `错误`是 GM 结算问题，修正状态变更后重调，不向玩家显示。
- go 返回 `错误`时按提示修正 action 后重调，不向玩家显示。
- 功能场景必须包含绑定功能 NPC 及对应 `特殊指令`，否则 judge 会拒绝。
- NPC 对话用引号，结构化名单中的人名用反引号；关系度变化不报数字，以态度表现。
- 隐藏要素不列入周围情况，待调查揭示。

玩家输入“指令查询”时，先列当前界面专用的自由行动说明，再读 [common-commands.md](./wuxia-rpg-common-commands.md) 补充通用指令。
