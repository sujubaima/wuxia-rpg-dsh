# exploration-ui 界面交互

正文由 engine 直出 `渲染文本`，GM 严格原样输出，包括空字符串。普通大世界 go 若无 `界面`，必须先按规则完成 judge，禁止直接拿 go 返回输出。

## 交互

- 玩家输入「指令查询」时，先列本界面专用的自由行动说明，再读 [wuxia-rpg-common-commands.md](./wuxia-rpg-common-commands.md) 补充通用指令。
- NPC 对话用引号，结构化名单中的人名用反引号；关系度变化不报数字，以态度表现。
- 隐藏要素不写入 `场景要素`，待调查揭示。

## 判定结果

判定提示属于 `剧情描写`，不属于剧情后的状态变化提示；具体格式、位置及数据后果处理见 [wuxia-rpg-exploration-rules.md](../wuxia-rpg-exploration-rules.md)「判定系统」。

## 首屏开场白

仅创建角色后的首轮 judge 使用。`当前剧情`依次包含：

1. 固定时代背景（逐字照搬）：

> 大明万历年间，天下承平日久，江湖却暗流渐起。
>
> 西域流沙之间，昔年被中原武林联手剿灭的无极教，竟以幽冥宫之名东山再起，兵锋渐指中原。而中原门派却各怀隐患，辽东与西南也隐有战端。江湖危机一触即发。

2. 据姓名、性别、年龄、人设、初始武学和落点撰写踏入江湖原由；只交代身世，不预设目的、伏笔或门派归属。
3. 首场景剧情与入门线索引子。

同时传首场景 `场景要素` 与初始 `经历概括`。功能场景必须包含绑定功能 NPC 及对应 `特殊指令`，否则 judge 会拒绝。

## 错误纪律

- judge 返回 `错误`是 GM 结算问题，修正状态变更后重调，不向玩家显示。
- go 返回 `错误`时按提示修正 action 后重调，不向玩家显示。
