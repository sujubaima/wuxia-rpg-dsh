# battle-ui 交互规则

engine 已将规范三层战报与玩家行动面板拼入顶层 `渲染文本`。成功返回时严格原样输出，不改写、润色、截断或按结构化字段重拼。

## 战斗流程

- `战斗-开始`由 judge 调用，返回战斗界面后原样输出 `渲染文本`。
- 玩家战斗 action 先调 go；若直接返回 `battle-end-ui`，立即原样输出。
- 非终局 go 无界面时，必须续调 judge `战斗-推进`，不得传 `战报文本`；再原样输出返回的 `渲染文本`。
- 已提交的战斗 action 不得重跑。judge 失败时只修正并重调 judge。

## 玩家指令

- `武学 [技能] [目标]` → `战斗-使用武学`
- `使用 [物品] [目标]` → `战斗-使用物品`
- `休息` → `战斗-休息`
- `逃跑` → `战斗-逃跑`
- `认输` → `战斗-认输`
- `查看人物信息`：按查询规则处理，不消耗战斗回合。

缺少参数时向玩家补问；不可执行时按 engine 错误修正，不得凭空改变可用性、目标范围或战局数据。禁止提供战术建议。

## 非我方胜终局

- 我方败/认输：依据敌方立场、动机和关系度处理未逃走的我方角色；逃走者不得处决。
- 平局：双方存活，不处决、不发经验。
- 终局界面输出后完成战后 judge，一次性提交合理后果与 `战斗-结束`，返回 `exploration-ui`；败方和平局不发经验。
- 我方胜或敌方认输按 [wuxia-rpg-battle-end-ui.md](./wuxia-rpg-battle-end-ui.md)处理。
