# message-ui 渲染规范

engine 返回 `界面=message-ui` 与 `提示` 时使用，承载参数缺失、资源不足、状态不满足、非法指令等玩家可见提示。

## 模板

━━ 模板开始 ━━
✗ {提示}

请重新输入指令：
━━ 模板结束 ━━

- `提示`必须原文照填，不改写、不补叙事。
- 纯通知而非失败时可省略「✗」。
- 不重绘前序界面，不附地点、时间、队伍或 GM 分析。
- judge 状态变更非法产生的 `错误` 是 GM 自检信号，不使用本界面，须修正后重调。
