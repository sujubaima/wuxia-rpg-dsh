# travel-ui 渲染规范

在驿站调用未指定目的地的 `远行（舟车）`，engine 返回 `界面=travel-ui`。玩家选定后再带目的地调用该 action。

## 模板

━━ 模板开始 ━━
### 【驿站 · {当前区域}】{驿站类型}

可往：
- `{目的地}`　{耗时}天　{金额}

请输入指令（前往 [目的地]、返回游历、可通过`指令查询`了解全部指令）：
━━ 模板结束 ━━

## 字段与规则

- `当前区域`、`驿站类型`填抬头；类型为水驿/陆驿/山驿/海驿/边驿。
- `路线`逐项取 `目的地/耗时/费用`；费用是铜钱数，格式化为不足千「X钱」、满千「X两X钱」。
- 列表为空时显示「此驿站暂无直达路线，需经他处换乘」。
- 只列 engine 返回的直达路线，不替玩家规划中转或选择目的地。

玩家输入“指令查询”时，先列本界面专用指令（前往目的地），再读 [common-commands.md](./wuxia-rpg-common-commands.md) 补充通用指令。
