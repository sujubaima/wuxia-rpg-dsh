# exploration-battle-ui 界面交互

judge `战斗-触发` 返回本界面，正文由 engine 直出 `渲染文本`（exploration-ui 抬头与叙事 + 战局双方 + 操控方式）。本界面只确认参战方与操控方式，不运行战斗。

## 交互

- 三种操控方式：玩家角色（仅操控主控）、我方全员（操控我方所有角色）、AI自动（我方全由 AI 操控，玩家观战至战斗结束）。
- 玩家选择后，复用本界面返回的 `我方/敌方/允许逃跑`，加入所选 `操控方式`，judge `战斗-开始`进入 battle-ui。不得替玩家选择或停在本界面不继续流程。
- 「指令查询」只说明三种操控方式及其效果。
