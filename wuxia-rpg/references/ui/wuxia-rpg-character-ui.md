# character-ui 界面交互

`角色信息` 返回本界面，正文由 engine 直出 `渲染文本`。一级属性、武艺与二级属性均采用 engine 返回的当前派生口径。

## 交互

- 专用指令：查看其他角色 [名称]、返回游历。
- 界面不展示阵营、关系度、完整武学栏或完整物品栏。
- 「指令查询」先列上述专用指令，再读 [common-commands.md](./wuxia-rpg-common-commands.md) 补充通用指令。
