# character-ui 渲染规范

engine 返回 `界面=character-ui` 时使用。一级属性、武艺与二级属性均采用 engine 返回的当前派生口径。

## 字段与规则

- `角色信息`提供名称、性别、年龄、经验值、当前/上限气血内力、一级属性、极性、武艺、技艺、二级属性、运转心法、携带技能、装备、携带物品与死亡状态。
- 极性并入一级属性表头；武艺含武学反哺与装备加成，二级属性与战斗派生同源。
- 空心法/携带列表显示「无」，空装备槽显示「空」。死亡角色在携带物品行末标「（已殁）」。
- 不展示阵营、关系度、完整武学栏或完整物品栏。

玩家输入“指令查询”时，先列本界面专用指令（查看其他角色），再读 [common-commands.md](./wuxia-rpg-common-commands.md) 补充通用指令。
