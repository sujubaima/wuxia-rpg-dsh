# wuxue-list-ui 渲染规范

engine 返回 `界面=wuxue-list-ui` 时使用。主动武学与心法分区完整列出。

## 模板

━━ 模板开始 ━━
### 【武学 · {角色}】

主动武学
- `{名称}` Lv{等级}（{类型} / {品名} / 威力{威力倍率} / 内力{内力消耗} / 冷却{冷却}）
　特效：{特效或无}

心法
- `{名称}` Lv{等级}（{品名}）
　特效：{特效或无}

请输入指令（查看其他角色 [名称]、查看武学详情 [武学]、返回游历、可通过`指令查询`了解全部指令）：
━━ 模板结束 ━━

## 字段与规则

- `角色`：抬头角色名。
- `主动武学`：取 `名称/等级/类型/品名/威力倍率/内力消耗/冷却时间/特效`。
- `心法`：只显示 `名称/等级/品名/特效`，不显示威力、内力、冷却和目标范围。
- 冷却0、特效空均显示「无」；任一区为空显示「（无）」；特效行以一个全角空格开头。
- 品级只显示 `品名`，不显示数字。

玩家输入“指令查询”时，先列本界面专用指令（查看其他角色、查看武学详情），再读 [common-commands.md](./wuxia-rpg-common-commands.md) 补充通用指令。
