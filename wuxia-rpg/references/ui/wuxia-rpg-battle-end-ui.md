# battle-end-ui 交互规则

我方胜或敌方认输时，engine 返回 `battle-end-ui`，并把完整终局战报与处决面板拼入顶层 `渲染文本`。严格原样输出，不改写战报或候选描述。

## 玩家答复与落盘

1. 按 `处决候选` 收齐每人的杀/放决定；不得默认、诱导、劝阻或自行增删候选。无候选时待玩家确认结束，使用空处置。
2. 调 go `战斗-处决`，`处置`逐人覆盖全部候选：`{角色,决定:杀|放,细节?}`；无候选传空数组或不传。
3. 该 go 只记录决定，不落盘死亡、经验、战利品、体力或时间，也不返回界面。
4. 随后做一次战后 judge，提交与答复一致的死亡/放归、go 返回的胜方经验、`战斗-结束`及合理的关系/剧情后果，返回 `exploration-ui`。

逃走者不在候选中，任何情况下不得处决；逃走者不发经验。战利品不自动获得，须由玩家后续搜刮。不得重跑战斗 action。
