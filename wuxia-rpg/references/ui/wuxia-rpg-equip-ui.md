# equip-ui 渲染规范

`配置装备` 未带操作参数时，engine 返回 `界面=equip-ui`；带 `操作+槽位` 执行穿/脱后仍返回刷新后的 equip-ui，`结算` 置于模板抬头后展示。

## 模板

━━ 模板开始 ━━
### 【更换装备 · {角色}】

{结算提示，如无则省略}

当前装备
- 武器1：{名称或空}{武器子类型}
- 武器2：{名称或空}{武器子类型}
- 护甲：{名称或空}
- 饰品：{名称或空}
- 冠巾：{名称或空}

可换装备
- `{名称}`（{子类型或类型}/{品名}）

请输入指令（装备 [物品] [槽位]、卸下 [槽位]、返回游历、可通过`指令查询`了解全部指令）：
━━ 模板结束 ━━

## 字段与规则

- `角色`：抬头角色名。
- `当前装备`：固定展示武器1/武器2/护甲/饰品/冠巾五槽；null 显示「空」。武器在名称后附子类型，如「长剑（剑）」；其余槽位不附。
- `可换装备`：逐项取 `名称/子类型/类型/品名`，品级只显示品名。
- 剑法、刀法、长兵、奇门、暗器须有任一武器槽类型匹配；搏击不受武器限制。

玩家输入“指令查询”时，先列本界面专用指令（装备、卸下），再读 [common-commands.md](./wuxia-rpg-common-commands.md) 补充通用指令。
