# wuxue-ui 渲染规范

`配置武学` 打开或修改后，engine 返回 `界面=wuxue-ui`。修改后的 `结算` 置于模板抬头后，随后刷新当前配置。

## 模板

━━ 模板开始 ━━
### 【更换武学 · {角色}】

{结算提示，如无则省略}

运转心法
- `{心法或无}`
　特效：{心法特效或无}

携带武学（{数量}/4）
- `{名称}` Lv{等级}（{类型} / {目标范围} / 威力{威力倍率} / 内力{内力消耗} / 冷却{冷却}）
　特效：{特效或无}

可用主动武学（已习得、未携带）
- `{名称}` Lv{等级}（{类型} / {目标范围} / 威力{威力倍率} / 内力{内力消耗} / 冷却{冷却}）
　特效：{特效或无}

请输入指令（运转心法、装上武学、卸下武学、替换武学、返回游历、可通过`指令查询`了解全部指令）：
━━ 模板结束 ━━

## 字段与规则

- `运转心法`为 null/空时显示「无」；`运转心法特效`空时显示「无」。心法独立于4个主动武学携带位。
- `携带武学`与`可用武学`逐项取 `名称/等级/类型/目标范围/威力倍率/内力消耗/冷却时间/特效`。
- 冷却时间0显示「无」；特效为空显示「无」。特效行以一个全角空格开头。
- 只能配置已习得武学，主动武学最多4门。

玩家输入“指令查询”时，先列本界面专用指令（运转、装上、卸下、替换），再读 [common-commands.md](./wuxia-rpg-common-commands.md) 补充通用指令。
