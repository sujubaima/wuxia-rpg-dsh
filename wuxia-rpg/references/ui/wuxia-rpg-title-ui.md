# title-ui 渲染规范

`开始游戏`返回 `界面=title-ui` 与**全部 slot**存档列表。标题主页、人物创建和标题态读档在本文件内闭环；标题态读档不同于游戏内只列当前 slot 的 save-ui。

## 二、人物创建

人物创建三步不调 engine，完成后才一次调用 go `创建角色`。

### 第一步：立名

━━ 模板开始 ━━
【人物创建】

—— 第一步 · 立名 ——

请告知姓名、性别与年龄（如：沈听雪，女，18岁）。

{错误提示，如无则省略}

请输入指令（姓名、性别、年龄、返回标题）：
━━ 模板结束 ━━

姓名、性别、年龄缺一则留在本步提示；年龄须16～80岁。

### 第二步：分配资质

  长兵 —— {长兵}　奇门 —— {奇门}　暗器 —— {暗器}

  音律 —— {音律}　弈棋 —— {弈棋}　诗书 —— {诗书}
  绘画 —— {绘画}　医术 —— {医术}　博物 —— {博物}

  阴阳 -- {内功极}（阴、阳、中）
  刚柔 -- {力道极}（刚、柔、中）
  动静 -- {身法极}（动、静、中）
  巧拙 -- {根骨极}（巧、拙、中）

{错误提示，如无则省略}

请输入指令（属性加点、随机分配、确认加点、属性含义、返回标题）：
━━ 模板结束 ━━

点数池固定：基础24、武艺36、技艺36；每项≤12。更新数字后重绘本面板；点数不合法时提示修正，不替玩家分配。

#### 属性含义

玩家询问时说明：

- 内功→攻击力、内力上限；力道→暴击、精准；身法→速度、防御力；根骨→识破、气血上限。
- 武艺六项分别增强同类武学的攻防能力。
- 音律用于奏乐酬答；弈棋用于手谈推演；诗书用于文书典籍；绘画用于鉴画制图；医术用于诊疗辨毒；博物用于察隐采掘。
- 阴：内力↑攻击↓；阳相反。刚：暴击↑精准↓；柔相反。动：速度↑防御↓；静相反。巧：识破↑气血↓；拙相反。中无修正。

说明后回到第二步面板。

玩家查询时调用 `wuxia_query`（`类型=武学`、`名称=[名称]`、`等级=1`；不可用时回退 `engine.py query`）取数，展示：

```text

{描述}

{目标范围，如有}

十境增益
| 等级 | 增益 |
|------|------|
| Lv1 | {增益或—} |
| … | … |
| Lv10 | {增益或—} |
```

十境逐行完整列出。无增益写「—」；复合增益逐项展开，正数加 `+`、多项用顿号连接，百分比保留 `%`。品级只显示品名。

### 完成建号

玩家确认初始武学后：

1. 按 [data-schema.md](../wuxia-rpg-data-schema.md) 组装完整角色 dict，须含 `人设`；二级属性、气血、内力及上限由 engine 派生，不传。
2. 将所选兵器写入角色 dict 的装备槽，按 [SKILL.md](../../SKILL.md) 标准调用格式执行 go `创建角色`。engine 新建 slot，并追加500铜钱、小还丹×2、补气丸×2及布衣。
3. 使用返回的新 slot 调 judge，按 [exploration-ui.md](./wuxia-rpg-exploration-ui.md) 写首屏开场白、初始剧情、场景要素与经历概括；该轮形成首份存档并进入 exploration-ui。

## 三、标题态读档

本分支使用 `开始游戏`返回的**全部 slot**列表，不调用游戏内 `存档列表`，也不使用 save-ui 的当前 slot 返回逻辑。

━━ 模板开始 ━━
【Slot_{slot} {角色名}】
- File_{序号} {年/月/日 时:分:秒} — {标签或进度}

请输入指令（选择存档、返回标题）：
━━ 模板结束 ━━

- 只列 `saves`非空的 slot；slot 按最近存档时间降序，各 slot 内 saves 按时间降序。
- 时间戳格式化为 `年/月/日 时:分:秒`。label 为空取该 slot 的 `进度`，均空显示「无」。
- 无任何存档时显示「尚无存档可续」。
- 选择存档后调 go `加载存档`进入 exploration-ui；返回则完整重绘标题主页。

## 跳转纪律

- 创建流程中输入错误时留在当前步骤并重绘，不替玩家选择。
- 任一步可返回标题主页；返回时完整重绘 ASCII 标题。
- 建号完成前不调 engine；标题态读档与游戏内 save-ui 不共享 action、数据范围或返回状态。
