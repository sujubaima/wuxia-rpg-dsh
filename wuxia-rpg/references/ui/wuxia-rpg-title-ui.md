# title-ui 交互规则

engine 已生成完整 `渲染文本`，GM 原样输出。创建草稿由响应返回、下一次 action 原样带回；建号前不在 slot 0 落盘。

## 标题操作

均走 go `标题-操作`：

```json
{"类型":"标题-操作","操作":"...","创建草稿":{}}
```

| 玩家意图 | `操作` | 追加参数 |
|---|---|---|
| 创建角色 | `开始创建` | — |
| 读取存档 | `读档` | — |
| 返回标题 | `返回主页` | — |
| 提交姓名性别年龄 | `提交立名` | `创建草稿`及本次`名称/性别/年龄` |
| 调整属性或极性 | `更新资质` | 完整`创建草稿`，可用`一级属性/武艺/技艺/极性`覆盖 |
| 随机分配 | `随机分配` | 完整`创建草稿` |
| 确认加点 | `确认资质` | 完整`创建草稿` |
| 查看属性含义 | `属性说明` | 完整`创建草稿` |
| 查看初始武学 | `武学详情` | 完整`创建草稿`、`武学` |
| 返回武学列表 | `返回武学选择` | 完整`创建草稿` |
| 返回上一步 | `返回上一步` | 完整`创建草稿`、当前`标题状态` |

输入不合法时 engine 仍返回 `title-ui`，并在 `渲染文本`内显示`校验提示`；不得改用`非法指令`或自行修正玩家选择。

## 完成建号

玩家选定初始武学后，以`开始游戏.next_slot`为顶层槽位调用：

```json
{"类型":"创建角色","创建草稿":{...},"初始武学":"太乙玄门剑"}
```

engine 校验点数、组装角色、配发对应武器及起始物资。仍兼容旧的`角色`完整 dict。创建成功后按正常流程调用 judge，写开场剧情、场景要素与经历概括，进入`exploration-ui`。

## 读档

标题态`读档`展示全部 slot；玩家选择后调用 go `加载存档`，`目标`可传 File_N、时间戳或标签。删除角色档前仍须确认。
