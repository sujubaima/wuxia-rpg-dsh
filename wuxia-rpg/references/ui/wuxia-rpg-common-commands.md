# 通用功能指令

仅在玩家输入“指令查询”时读取。先列当前 UI 文档规定的专用指令，再追加下列适用的通用指令；当前界面已有同名指令时不重复。

## 大世界功能

- 自由行动：移动、对话、调查、观察、切磋、查找或使用物品。
- 休息：客栈内进入休息界面；露宿等用自然语言说明地点与时长。
- 精进武学：消耗经验，使已习得武学精进一境。
- 配置武学：调整战斗携带武学与运转心法。
- 配置装备：调整武器、护甲、饰品与冠巾。
- 配置道具：调整战斗携带消耗品。
- 查看背包：查看物品栏，可按类型、子类型或适用场合筛选。
- 查看线索：查看进行中与已关闭线索。
- 查看地图：查看当前区域已知场景和相邻路线。
- 查看武学：查看角色已习得的主动武学与心法。
- 角色信息：查看自己或队友的角色信息。
- 保存游戏：填写存档标签并保存当前进度，不跳转界面。
- 读取存档：进入游戏内读档界面，仅浏览当前角色槽位的存档。
- 返回游历：退出当前子界面，回放大世界 exploration-ui。

## 固定尾行

```text
请输入指令（可通过`指令查询`了解全部指令）：
```
