# save-ui 渲染规范

游戏进行中调用 `存档列表`，engine 返回 `界面=save-ui` 与**当前 slot**的存档列表。该流程不同于 title-ui 的全部 slot 浏览，不复用标题态调用或跳转。

## 模板

━━ 模板开始 ━━
【读档 · Slot_{槽位} {角色名}】

- File_{序号} {年/月/日 时:分:秒} — {标签或进度}

请输入指令（选择存档、返回游历）：
━━ 模板结束 ━━

## 字段与规则

- `存档列表`只含当前 slot；按时间戳降序完整列出。
- 每项取 `序号/时间戳/label`；时间戳格式化为 `年/月/日 时:分:秒`。label 为空时显示当前进度，均空显示「无」。
- 列表为空时显示「当前角色尚无可读取存档」。
- 玩家选择 File_N 后，以该存档目标调用 `加载存档`，返回 exploration-ui。
- 玩家选择返回时调用 `返回游戏`，回放当前 exploration-ui；不返回标题页，也不浏览其他 slot。
