# 数据字段说明

基线数据位于 `assets/data/`，但 GM 只经 `wuxia_query` 等查询工具（不可用时回退 engine 查询命令）读取、经 engine 写入，禁止直接读写 JSON。具体查询见 [wuxia-rpg-dao-query.md](./wuxia-rpg-dao-query.md)。

## 角色

| 字段 | 说明 |
|------|------|
| 名称 | 显示名及条目名 |
| 性别 / 年龄 | 基本信息 |
| 阵营 | 预设角色通常为门派/势力名；玩家可为「我方」；散人/自创组织成员统一归「江湖」 |
| 一级属性 | 内功/力道/身法/根骨 |
| 极性 | 阴阳、刚柔、动静、巧拙四组倾向 |
| 武艺 | 搏击/剑法/刀法/长兵/奇门/暗器，单项上限25 |
| 技艺 | 音律/弈棋/诗书/绘画/医术/博物，单项上限25 |
| 武学 | `[{名称,等级}]`，等级1～10 |
| 运转心法 | 已习得心法名或 null |
| 携带技能 | 战斗携带主动武学名，最多4门；缺省回退全部已习得 |
| 携带物品 | 战斗携带消耗品种类名，最多4类；缺省为空 |
| 装备 | 武器1/武器2/护甲/饰品/冠巾 |
| 物品 | 完整物品栏，无容量上限 |
| 经验值 | 初始0、无上限，用于武学精进 |
| 铜钱 | 货币，1两=1000钱 |
| 关系度 | 0～100，初始50 |
| 死亡 | 布尔；败阵/逃走不会自动死亡，须经战后 judge 处决 |
| 人设 | 性格与背景，经 `wuxia_setting` 查询 |
| 战斗风格 | 平衡/勇猛/谨慎，仅 AI 操控时生效，缺省平衡 |
| 持久化 | 自创角色可选；false 表示不再登场的龙套，读档即逝；预设角色永远持久化 |

`二级属性`、气血/内力及上限由 engine 从一级属性、极性、武学和装备派生，新建时不传。

### 创建角色/写临时 NPC 模板

必填：名称、性别、年龄、阵营、一级属性、极性、武艺、技艺、武学、人设。临时龙套可加 `持久化:false`。

```json
{
  "名称":"沈听雪","性别":"女","年龄":18,"阵营":"我方",
  "一级属性":{"内功":6,"力道":5,"身法":4,"根骨":5},
  "极性":{"内功":"阴","力道":"刚","身法":"动","根骨":"巧"},
  "武艺":{"搏击":3,"剑法":10,"刀法":4,"长兵":4,"奇门":3,"暗器":6},
  "技艺":{"音律":5,"弈棋":6,"诗书":6,"绘画":3,"医术":6,"博物":4},
  "武学":[{"名称":"太乙玄门剑","等级":1}],
  "携带技能":["太乙玄门剑"],"携带物品":[],"运转心法":null,
  "装备":{"武器1":"长剑","武器2":null,"护甲":null,"饰品":null,"冠巾":null},
  "物品":[],"人设":"初入江湖的少女剑客……"
}
```

## 武学

| 字段 | 说明 |
|------|------|
| 名称 / 描述 / 招式 | 显示名、战报描写、招式名数组 |
| 品级 | 数字等级；null为未定级 |
| 类型 | 剑法/刀法/长兵/奇门/暗器/搏击/心法 |
| 威力倍率 / 内力消耗 / 冷却时间 | 主动武学基础数值 |
| 目标范围 | 缺省敌方单体，可为敌方全体等 |
| 技能特效 | 武学附带的机制效果 |
| 识破类型 | 独立/全体/自对抗/无；带特效但缺省时视为独立 |
| 自身特效 / 队友特效 | 对自己或我方全体施加的状态 |
| 心法效果 | 运转心法时施加的长效状态；空时以小周天占位 |
| 等级增益 | Lv1～10的 `{等级,效果}`；折算见 [wuxia-rpg-formulas.md](./wuxia-rpg-formulas.md) |

心法不可主动施展，不占主动武学携带位；通过 `运转心法`生效。空 `心法效果`自动施加小周天，每回合结束回复5%气血与内力上限。

## 状态效果

| 字段 | 说明 |
|------|------|
| id / 名称 | 机制标识与中文显示名 |
| 类型 | 正向/负向/中性，对应绿/红/黄 |
| 效果 | 纯机制短描述 |
| 叠加方式 | 不可叠加/可叠加/可延长 |

## 阵营

字段：名称、描述、地理位置、成员、武学。

## 物品

| 字段 | 说明 |
|------|------|
| 名称 | 显示名及条目名 |
| 类型 | 武器/护甲/冠巾/饰品/消耗品/材料/其他 |
| 子类型 | 武器类型、`<武学类型>秘籍`、技艺书、丹药、道具、食物、材料等 |
| 品级 | 0～3，对应凡品/上品/珍品/绝品 |
| 描述 / 价格 | 文学描述与铜钱基础价 |
| 装备效果 | 穿戴后由 engine 自动生效的属性或机制效果 |
| 使用效果 | 消耗品纯数据效果，见下 |
| 物品特效 | 可选；引用 `scripts/effects/items/` 下的战斗脚本 |
| 适用场合 | 战斗/世界/通用，由 engine 自动校验 |
| 武学 | 秘籍所授武学名，不带书名号 |

### 子类型规则

- **秘籍**：名称用《》；`子类型=<武学类型>秘籍`，`武学`填所授名称，品级与武学一致，适用世界。研读后习得或精进一层并消耗秘籍。
- **技艺书**：名称用《》；`使用效果={"技艺":{技艺名:N}}`，适用世界，单项最多25。
- **丹药**：适用战斗。效果为回复气血/内力、施加状态、净化、削减或延长之一；施加状态可用`层数`指定叠加次数。
- **道具**：适用战斗。效果为施加状态或改变目标时序。
- **食物**：适用世界。可回复气血与体力，不进入战斗携带列表。

各子类型均经 `使用物品` action 统一进入 engine，由 engine 分流；GM 不自行执行效果。
