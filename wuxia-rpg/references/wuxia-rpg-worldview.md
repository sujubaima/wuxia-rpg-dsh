# 世界观与背景

大世界探索入口文档。本文只记**世界观叙述、已开放地区、地区故事线索引**；故事线细节见 [wuxia-rpg-storylines.md](./wuxia-rpg-storylines.md)，玩家涉入对应地区/事件时按需补读；门派、人物和武学具体设定见文末「设定查询」。

## 一、世界观与背景的整体叙述

**明朝万历年间**，江湖与朝堂交织，正邪、官民、恩怨一触即发。

最大主线是魔教**幽冥宫**与中原武林的冲突。幽冥宫乃昔年被剿灭的无极教余孽，教主石自然蛰伏后悟出绝世武功、于西域东山再起，下设五玄使，收留天下大奸大恶之辈，声势煊赫、染指中原。中原四大门派却各怀隐患：少林主守、武当主战，正道群龙无首；丐帮前帮主被害成谜、现帮主隐踪；峨眉释道二门反目。抗魔合力能否成型，是最大悬念。庙堂边患亦为变数：锦衣卫与东厂暗中角力，不容以武犯禁；戚家军残部结**风云盟**据港独力御倭，与朝廷貌合神离；辽东女真渐统、频派探子南下。

主线之下，各派世仇、嫡庶、兴衰纠葛暗流涌动；另有暗杀组织**乌衣门**、邪道**长生坛**等身份不明的暗影，与魔教东进、朝堂角力彼此缠绕，真相待玩家深入方能揭开。

### 次要区域

非门派据点的补充游历去处，丰富市井、商贸、宗教、漕运维度。GM 据剧情自由安排子场景，地点间移动开销贴近真实地理。

| 区域 | 驿站 |
|------|------|
| 金陵 | 水驿 |
| 临清 | 水驿 |
| 洞庭湖（岳阳） | 水驿 |
| 庐山 | 水驿 |
| 关中（西安） | 陆驿 |
| 河西（兰州） | 边驿 |
| 广州 | 海驿 |

> 次要区域不绑定门派，多作市井游历、商贸往来、清修炼心之所；其故事线由 GM 据既有伏笔与玩家行动就地生发。次要区域亦可是江湖散人、非门派干部类预设 NPC 的出没之地（前提是不与人设冲突）。

## 三、地区故事线索引

全局鸟瞰——各区域挂哪些活跃线，**判定地域归属（准则第16条）与设计引子时查此表**；具体展开补读 [wuxia-rpg-storylines.md](./wuxia-rpg-storylines.md) 对应区块。

| 区域 | 故事线/伏笔（详见 storylines.md） |
|------|----------------------------------|
| 苏州 | 两派世仇；【西河剑法】之谜；穆双清与商河洛旧情；跨派禁忌线（骆逸×朱如碧）；太湖水寨之患；万飞鹏残刀 |
| 杭州 | 风云盟路线之争；锦衣卫觊觎【辛酉刀法】 |
| 正邪大局（少林/武当/丐帮/峨眉/华山/昆仑） | 少林之变；正邪之争；武当力度三分；丐帮之危；峨眉分裂；魔教东进；华山论剑之期；昆仑监视魔教 |
| 悬案暗线（跨地域） | 黄金颊之谜；乌衣门之影；通天七剑；圆隆身世；婴青凤寻魂；婴青凤与阿鹊；六如棍法断壁 |
| 朝堂与边患 | 厂卫角力；倭患再起；长鲸与平户；迷仙寨用兵；密宗使中原；女真窥明 |
| 其他暗流 | 长生坛之异；青城夺蜀；百兵堂三暗线；中原外务网 |

> 开局按准则第15条先以小任务铺底，不急于牵主线；背景信息在玩家深入事件后逐步揭示（准则第4、13条）。
