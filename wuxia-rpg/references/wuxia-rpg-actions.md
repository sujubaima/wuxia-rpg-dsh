# 行为与状态变更契约

本文件是 `行为` 数组参数的唯一权威来源。意图路由见 [SKILL.md](../SKILL.md)，推演原则见 [wuxia-rpg-exploration-rules.md](./wuxia-rpg-exploration-rules.md)。

- **go 行为**：玩家主动指令；行为类通常消耗体力/时间，配置与查询类不消耗。
- **judge 条目**：GM 推演结果，包括状态变更及战斗触发/开始/推进。

时间统一用刻：1时辰=8刻，1天=96刻。

## go：大世界行为

| 类型 | 参数 | engine 语义 |
|------|------|-------------|
| `休息` | `等级`(露宿/简朴/中等/奢华),`时长`,`免费`(必传bool) | 露宿每时辰回10体力；简朴/中等/奢华每刻4/5/6钱，每时辰回15/20/25体力及上限15%/20%/25%气血内力。免费时费用0；恢复由 go 完成，judge 不重复 |
| `远行（徒步）` | `目的地` | 区域内按登记场景图寻路；每边消耗5体力、4刻。跨区域、不连通、原地均报错 |
| `远行（舟车）` | `目的地`(可省) | 无目的地打开远行界面；有目的地须位于驿站，扣路线费用、推进天数、补满体力并抵达 |
| `使用物品` | `物品`,`目标`(默认主控) | 大世界统一入口，扣1体力1刻；engine 按子类型处理秘籍、技艺书、食物等，并校验适用场合 |
| `购买` | `卖家`,`物品`,`数量`,`价格`,`商人`,`买家`(默认主控),`标签` | 无物品打开购买界面；有物品扣2体力2刻、铜钱并入栏。`商人`表示本次是否货架交易 |
| `出售` | `买家`,`物品`,`数量`,`价格`,`商人`,`卖家`(默认主控) | 无物品打开出售界面；有物品扣2体力2刻、物品出栏并加铜钱 |
| `赠与物品` | `物品`,`受赠者`,`数量`(默认1),`赠送者`(默认主控) | 扣1体力1刻并转移物品；受赠者须已落盘，随后 judge 承接反应/关系度 |
| `遣散` | `角色` | 遣散费=一级属性和×10；铜钱不足则关系度-20并离队，随后 judge 写剧情善后 |
| `交谈观察` | — | 扣1体力、1刻；剧情及数据后果由 judge 承载 |
| `其他行为` | `描述` | 无法归类的杂项动作，扣4体力、2刻，后续由 judge 承载 |
| `攻击` | `目标`(可选) | 扣1体力、1刻；是否触战由 GM 推演，触战经 judge `战斗-触发` |

## go：配置、查询与系统行为

| 类型 | 参数 | 语义 |
|------|------|------|
| `配置装备` | `角色`,`操作`(穿/脱),`槽位`,`物品`(穿时) | 无操作打开装备配置；有操作穿脱五类槽位 |
| `配置物品` | `角色`,`操作`(装/卸/换),`物品`,`目标物品`(换时),`携带物品`[](≤4类) | 配置战斗携带消耗品 |
| `配置武学` | `角色`,`操作`(装/卸/换),`武学`,`目标武学`(换时),`携带技能`[](≤4),`运转心法` | 配置已习得主动武学或心法 |
| `武学精进` | `角色`,`武学`,`操作`(精进) | 无武学列出可选武学；有武学无操作查看十境表；精进消耗经验升一境。秘籍研读走 `使用物品` |
| `角色信息` | `角色` | 角色必填 |
| `查看背包` | `筛选类型`,`筛选子类型`,`适用场合`(可选) | 类型/子类型可传单值或数组 |
| `查看地图` | `当前场景`(可选) | 据当前位置展示区域地图；必要时用参数补全并持久化当前场景 |
| `查看线索` | — | 列出当前已获线索及进展 |
| `武学列表` | `角色` | 返回该角色全部主动武学与心法；角色必填 |
| `战斗-使用武学` | `武学`,`目标` | 推进战斗一轮；go 无界面，随后 judge `战斗-推进` |
| `战斗-使用物品` | `物品`,`目标` | 同上 |
| `战斗-休息` | — | 同上 |
| `战斗-逃跑` | — | 个人逃跑判定；同上 |
| `战斗-认输` | — | 认输方整队判负；同上 |
| `战斗-处决` | `处置`[]：`{角色,决定:杀\|放,细节?}` | 我方胜后逐人记录处决答复，不落盘任何状态；go 无界面 |
| `标题-操作` | `操作`,`创建草稿`及步骤参数 | 无状态驱动标题主页、全槽位读档和三步创建；具体操作见 title-ui 文档 |
| `创建角色` | `角色`完整dict，或`创建草稿`+`初始武学` | 顶层`槽位`须用`开始游戏.next_slot`；冲突返回最新编号；成功后 judge 写开场与首份存档 |
| `保存游戏` | `标签`(必填),`经历概括`(可选) | 手动存档，标签不得为空 |
| `加载存档` | `目标` | 目标可为 File_N、时间戳、label或子串 |
| `删除存档` | `目标`(可选),`槽位`(可选) | 有目标删单个存档点，无目标删整个角色档；调用前必须确认 |
| `存档列表` | — | 当前 slot 的存档列表 |
| `开始游戏` | — | 全部 slot 的存档列表及`next_slot` |
| `非法指令` | `提示` | 不结算、不落盘、不推进 |
| `返回游戏` | — | 回放当前游历界面 |

## judge 顶层字段

```json
{"槽位":1,"行为":[...],"当前剧情":"...","场景要素":[...],"经历概括":"..."}
```

- `当前剧情`必填，作为返回的 `剧情描写` 原样使用；战斗推进轮可空。
- `场景要素`可选，维持3～5项：`{主体,描写?,特殊指令?}`。特殊指令为对象数组 `[{名称,可用}]`，`可用` 为 bool（GM 据场景判断：玩家被困、店铺打烊等情形置 false，前端据此置灰禁用）。功能场景的功能 NPC 必带对应特殊指令（按名称校验，与可用性无关）；其要素 `主体` 以功能 NPC 名开头即可，如「驿丞」「驿丞陈四」均可。
- `经历概括`可选，传精简后的全量概括以覆盖旧值。

## judge：战斗条目

| 类型 | 参数 | 语义 |
|------|------|------|
| `战斗-触发` | `我方`[],`敌方`[],`允许逃跑` | 不开战，仅确认参战方与操控方式 |
| `战斗-开始` | 上述三项+`操控方式`(玩家角色/我方全员/AI自动) | 启动战斗；战斗本身不推进大世界时间 |
| `战斗-推进` | `回合详情`(可选) | 打包上一轮 go 缓存的规范战报；不得传 `战报文本`，`回合详情`仅作结构化兼容 |

## judge：状态变更

每项格式为 `{"类型":...,"操作":...,"角色":...,...}`。

| 类型 | 操作与参数 |
|------|------------|
| 铜钱 / 经验 | `加/减`,`值` |
| 关系度 | `加/减`,`角色`,`值` |
| 物品 | `增/减`,`名`,`数量`(默认1) |
| 使用物品 | `物品`,`目标`；不自动扣体力/时间，需要时另传条目 |
| 装备 | `穿/脱`,`名`,`槽位` |
| 携带技能 / 携带物品 | `设`,`名列表`(≤4) |
| 运转心法 | `设`,`名`；卸下填「无」 |
| 技艺 | `加/减`,`名`,`值` |
| 在队 | `入/离`；离队可带`原因` |
| 气血 / 内力 / 体力 | `设/加`,`值` |
| 时间 | `加`,`值`(刻) |
| 死亡 | `处决`,`角色` |
| 写角色 | `角色`完整dict；重名则整轮回滚，自创龙套可带`持久化:false` |
| 抵达 | `位置`；仅用于被押送、传送等非远行式到达 |
| 武学 | `精进/习得`,`名`；剧情性授武用，秘籍研读不用 |
| 战斗-结束 | 无参数；自动体力-20、时间+8刻，战后 judge 必带 |
| 登记场景 | `区域`,`场景`,`方位出口?`,`功能类型?`,`功能NPC?`；新地点、孤点与功能场景规则见 exploration-rules |
| 隔离地点 | `区域`,`场景`；清空该地点及反向出口，使其成为孤点 |
| 线索 | `名称`,`进展节点`完整列表,`关闭?`；按名称合并、节点整体替换 |

判定提示不是状态变更，不得放入 `行为` 或 `结算`。
