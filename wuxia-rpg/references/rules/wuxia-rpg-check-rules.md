# 判定系统

### 强制原则

1. 所有判定必须经 `wuxia_check` 工具（不可用时回退 `engine check` 命令）掷骰，不得手算、自行掷骰或先写结果。
2. 判定项只能是技艺（音律、弈棋、诗书、绘画、医术、博物）或一级属性（内功、力道、身法、根骨）。
3. 判定角色只能是主控或队友；NPC 的应对由 GM 据人设与属性裁定。
4. 优先选择贴合行动性质的技艺，确无合适技艺才用一级属性。

### 何时判定

凡行动成败、效果好坏或后续走向依赖角色水平，存在不确定性或对抗对象，即应判定。每次 judge 前必须主动检查，不得因剧情已有预想而跳过。

须先掷骰，再严格依据成功或失败继续推演；不得掷骰后仍沿用原定剧情。宁可多判，不可漏判。氛围性判定也可执行，但无实质线索推进时不发经验、不更新线索。

### 成功率

```text
最终成功率 = clamp(基础成功率 + (角色判定值 − 对抗等级) × 10%, 5%, 95%)
```

基础成功率：易70%、普通50%、困难30%、极难15%。有对手时取对方对应值，多人取均值；无对手时由 GM 设对抗等级。除特殊情形，优先选队伍中该项数值最高者。

### 判定项参考

| 判定项 | 典型场景 |
|--------|----------|
| 音律 | 奏乐酬答、以乐动情、辨曲中暗号 |
| 弈棋 | 手谈破局、推演阵法、解残局 |
| 诗书 | 题诗和答、文书辨伪、典籍与密信 |
| 绘画 | 鉴画、绘制通缉像或地形图、画中藏密 |
| 医术 | 诊脉、辨毒、疗伤、验尸、识蛊 |
| 博物 | 察觉隐藏信息与陷阱、采集挖掘 |
| 内功 | 运气探脉、内功机关阵法、隔空感应 |
| 力道 | 搬运、破门、攀援、角力 |
| 身法 | 潜行、翻越、走险、追逃 |
| 根骨 | 直觉、辨真伪、抗毒蛊、强记、镇定 |

### 展示纪律

- 判定命令与参数见 [wuxia-rpg-dao-query.md](../wuxia-rpg-dao-query.md)「判定掷骰」。
- 成功率、掷骰数等数字不得向玩家展示。
- 将脚本返回的 `提示` 字段反引号高亮，自然嵌入 judge `当前剧情`中与判定行动及结果直接对应的叙事位置；不得机械置于描写开头或结尾，不改写、不附数字。
- 判定结果不是状态变化，不得写入状态变更条目或 `结算` 数组。
- 掉落判定同样隔离数字，只在剧情中写获得或未获得。
