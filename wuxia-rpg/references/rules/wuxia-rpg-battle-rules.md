# 战斗规则

### 触发战斗

大世界触战分三类：

- **玩家主动触战**：据意图确定参战方，经战前选择界面确认操控方式后开战。
- **NPC 主动发起**：须先给察觉与反应空间。非死战可让玩家以逃跑、交涉、隐匿等合理手段规避，并按规则判定；失败才入战。死战不可规避。
- **随机事件触发**：移动随机事件中的战斗类直接进入战前流程。

参战角色由 GM 据现场确定，敌方可用预设角色或符合规则的自创角色。

**攻击失能目标**：目标醉酒、重伤、熟睡、被缚等无有效抵抗能力时，可用判定代替战斗；成功达成攻击意图，失败则视情况未得手或转入战斗。目标仍可抵抗或已形成正式交战时，照常开战。

### 战斗经验

经验值初始 0、无上限，用于武学精进。

**获胜经验**：

- 单个敌人经验 = `(敌人一级属性之和 / 10)² × 80`
- 均分额 = `敌人经验总和 / 我方参战人数`
- 角色所得 = `均分额 × (1 + 经验加成/100)`
- 仅胜方获得；逃走者、败方、平局均不得经验

**线索节点经验**：

- 单人所得 = `节点奖励经验 / 在队人数 × (1 + 经验加成/100)`，取整累加
- 可分散在各节点发放，也可在解决时集中发放
- 判定本身不单独给经验

品级 0 武学精进锚点：Lv1→2 为 640、2→3 为 1040、3→4 为 1381、4→5 为 1689、5→6 为 1975。

**多解收益平衡**：

1. 战斗额外经验是风险补偿，总收益略高合理。
2. 和平或智取路线以节点经验补足，目标总收益不低于战斗路线的 60%。
3. 设计多解线索时预估并校准各路线收益，避免单一路线碾压。

### 战后处置

战斗结束后、返回大世界前必须完成战后处置，规则对双方一致：胜方处置败方。

- 气血归零只代表败阵，不等于死亡。
- 逃走者已脱离战场，不构成离队，也不在胜方手中，禁止处决。
- 未逃走的败方须逐人决定杀或放，不得默认死亡，也不得在决定前落盘。
- 我方胜：由玩家逐人决定敌方败阵者杀/放。
- 我方败或认输：GM 据敌方立场、动机、关系度逐人决定；非必杀可改为掠财、羞辱、俘虏、勒索或重伤弃置。主控死亡则存档终结。
- 平局：双方存活，不处决、不发经验，由 GM 合理推动收场。
- 杀放可影响相关人物关系度，GM 据人设裁定。

战后 judge 一次性落盘：杀放结果、胜方经验、`战斗-结束`、关系度及其他后果。具体条目见 [actions.md](../wuxia-rpg-actions.md)；我方胜终局见 [battle-end-ui.md](../ui/wuxia-rpg-battle-end-ui.md)，其余战局见 [battle-ui.md](../ui/wuxia-battle-ui.md)。

自创 NPC 需死亡时，若尚未落盘，可在同轮 judge 先「写角色」再「死亡」；已落盘者直接处决。死亡后不得正面登场。

### 战利品

胜利只自动结算经验，不自动发钱或物品；战利品须由玩家搜刮尸体或现场获得。

- 铜钱：按身份强弱拟定，龙套数十至数百，高手可达数千以上。
- 物品：从其身份、所属势力可能持有的预设物品中安排；龙套仅品级 0～1。
- 候选掉落率：品级0约30%、1约20%、2约12%、3约7%、4+约3%。
- 隐藏物品须经博物判定发现。
- 已搜刮的尸体不得重复搜刮。
