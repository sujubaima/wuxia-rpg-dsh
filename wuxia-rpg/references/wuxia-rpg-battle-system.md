# 战斗引擎内核

本文件供理解和扩展代码；日常战斗由 `engine.py`协调 `battle.py`，GM 推演与界面规则见 [wuxia-rpg-exploration-rules.md](./wuxia-rpg-exploration-rules.md)和 [wuxia-rpg-battle-ui.md](./ui/wuxia-rpg-battle-ui.md)。

## 流程与模式

```text
初始化角色 → AI推进至玩家回合 → 玩家行动 → AI继续推进 → 循环至终局
```

一次引擎调用等于一个“玩家回合间隔”。对战分组必须显式指定，不按角色 `阵营`自动分队。

- **auto**：执行玩家指令并推进全部后续 AI 回合至下个玩家回合；输出 `结算列表`。
- **single**：仅执行一个角色一次行动，供调试；输出单个 `结算`。
- `玩家角色`为空时纯 AI 推进至战斗结束。

角色必需名称、阵营、一级属性、极性、武艺、武学、装备；二级属性与气血内力可省略，由引擎派生并填满。

## 胜负与退场

- 一方全员败阵、逃走或混合退出时，对方获胜。
- 气血归零只标记败阵，停止充能和行动，不等于死亡。
- 逃跑成功只退出本场，气血不变、不离队、不得经验，也不得被处决。
- 生死由战后 judge 决定；战斗引擎不写角色 `死亡`。

## 行动与输出

内部行动：

- 武学：完整技能对象+目标。
- 物品：完整物品对象+目标，占一回合并扣物品栏。
- 休息：回复10%最大内力，不回气血。
- 逃跑/认输：按战局规则结算。

核心输出：

```json
{
  "结算列表":[...],"战场状态":{...},"行动预告":[...],
  "战斗结束":null,"经验结算":{...}
}
```

`战场状态`直接供下次输入。终局才返回经验；只计算胜方未逃走角色，engine 不落盘，由战后 judge逐项写经验。

回合结算可含伤害、闪避、暴击、气血/内力变化、状态得失、时序变化及全体/自对抗特效的共享掷骰结果。

## AI 决策

AI 从可用武学×目标、可用物品、休息、逃跑、认输中统一评分并加权抽样；无可用武学/物品时休息。

### 战斗风格

- **平衡**：综合威力、特效、物品、休息与脱身。
- **勇猛**：偏高威力、少休息、几乎不逃不降、较少用物品。
- **谨慎**：偏低耗、保命物品与休息，劣势时更易逃降。

### 评分要点

- 技能：威力+特效战术价值；需识破的特效按发动率折算，可在 `SKILL_OVERRIDES`定制。
- 目标：残血补刀与攻击威胁共同决定，乘数0.5～1.5；单体技能逐目标成为候选。
- 物品：回血按缺血比例，控制按敌方威胁，净化/削减按状态数量；评分≤0不参与。
- 休息：残血和缺内力时升高；心疾等无法恢复者价值极低。
- 逃跑/认输：按双方队伍总气血百分比差距二次增长；逃跑权重高于认输。勇猛权重0，谨慎较高。

逃跑为个人行动：成功退出、失败消耗回合；全员退出才判负。认输使整队判负。玩家操控战中，我方 AI 队友禁止擅自逃跑或认输；纯 AI 战不受此限。

## 统一战斗阶段

技能、物品和状态共用 `on_xxx(source, ctx)`。每阶段先执行当前行动特效，再执行阶段开始时快照的全场状态；同一持有者的同一状态ID聚合为一个来源。同阶段新状态不补调，后续阶段可参与。

| 钩子 | 时机 |
|------|------|
| `on_action` | 行动成立后，每次行动一次 |
| `on_target_check` | 每目标闪避判定前 |
| `on_target_confirmed` | 目标未闪避后 |
| `on_damage_calc` | 基础伤害与暴击计算后 |
| `on_settle` | 普通结算改写 |
| `on_before_commit` | 最终保命与抵挡处理 |
| `on_damage_resolved` | 实际伤害确定、写账前 |
| `on_target_resolved` | 目标落账且仍在场后 |

技能特效受识破门控，状态钩子不受影响。「全体/自对抗」共享一次结果，「无」必发，「独立」在每个未闪避目标上掷一次并复用至该目标后续阶段。物品脚本不新增闪避和识破。

`settle`依次执行 `on_settle`、`on_before_commit`再写账；消耗预演只执行普通结算改写，不提交。生命周期、回合、属性、消耗、冷却、武器查询和各类过滤器保留专用接口。

## 心法与状态生命周期

- 心法在初始化时施加，幂等；心法不能主动使用。
- 剩余时间<0为长效状态，战斗中不递减，战斗结束清除。
- 状态记录来源、来源类型、施加者和场景。
- 战斗计时、战斗结束清理及净化/削减/延长只作用于战斗场景状态；大世界状态不参与战斗结算。

## 入口与核心函数

`battle.py`模式由 `--player`决定：无玩家为纯 AI；有玩家使用 start/go/info。`--teams "A,B;C,D"`必填，`--slot`读取存档，`--seed`固定随机；`stats`只输出派生属性。战斗有50回合安全上限。

核心函数：

| 函数 | 用途 |
|------|------|
| `auto_advance` / `process_turn` | 自动推进 / 单行动 |
| `derive_secondary` | 派生二级属性 |
| `ai_decide` / `execute_action` | AI选行动 / 执行动作 |
| `dispatch_combat_stage` | 技能/物品/状态统一阶段分发 |
| `settle` / `commit_settle` | 结算钩子与统一写账 |
| `get_active_skill_names` | 可上场主动武学，最多4门 |
| `get_battle_items` | 可上场消耗品，最多4类 |

公式见 [wuxia-rpg-formulas.md](./wuxia-rpg-formulas.md)，命令示例见 battle.py 帮助与 battle-ui。
